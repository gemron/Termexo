# AgentDock V0.1 架构

## 范围

本版本实现可运行的桌面工作台基础，不包含跨 Agent 会话扫描、Git
worktree 自动编排、密钥存储和完整模型切换事务。这些能力继续按
`AgentDock.md` 的 V0.2 至 V0.5 规划演进。

## 模块职责

- `apps/desktop-ui/src/app/core/models`：前端领域模型与固定状态。
- `core/services/app-state.service.ts`：Workspace、终端和布局状态。
- `core/services/workspace.repository.ts`：Tauri SQLite 与浏览器
  `localStorage` 的持久化适配。
- `core/services/terminal-gateway.service.ts`：真实 PTY IPC 与浏览器预览适配。
- `workspace`、`terminal`、`inspector`：独立展示组件。
- `src-tauri/src/pty`：PTY 进程、输入输出、Resize 和关闭。
- `src-tauri/src/database`：SQLite migration 与 Workspace 快照。
- `src-tauri/src/commands`：稳定、窄接口的 Tauri IPC 命令。

## 恢复语义

应用重启后恢复的是 Workspace 配置、终端目录、启动命令和布局，而不是
已经退出的操作系统进程。Desktop Core 会创建新的 PTY，并在后续
Adapter 中调用各 CLI 的原生 Resume 命令。

## 后续接口

V0.2 将在 `src-tauri/src/agent` 增加 `AgentAdapter`，保持会话扫描、
命令构造、输出解析和模型切换各自独立。Workspace 快照中的
`nativeSessionId` 已为原生会话恢复预留字段。
