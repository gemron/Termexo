# AgentDock V0.2 架构

## 范围

V0.2 在 V0.1 的 Workspace、PTY 和 SQLite 基础上增加 Claude Code
专用纵向闭环：安装检测、只读会话扫描、原生 Resume、Hooks 状态识别、
模型/API Profile 和 MCP Profile。

本版本不包含 Codex/Gemini Adapter、跨 Agent 模型切换、会话迁移、
Worktree 编排和自动权限批准。

## 后端模块

- `src-tauri/src/agent`：`AgentAdapter` 领域接口和 `ClaudeCodeAdapter`。
- `src-tauri/src/hooks`：Claude 临时 Hooks 配置、外部事件采集和状态映射。
- `src-tauri/src/config`：系统凭据访问和一次性终端启动环境。
- `src-tauri/src/database`：Workspace、会话索引、Profile 和事件持久化。
- `src-tauri/src/pty`：注入一次性环境后启动 PowerShell 与 Claude。
- `src-tauri/src/commands`：检测、扫描、启动准备、事件同步和 Profile IPC。

## 前端模块

- `core/services/agent.service.ts`：Agent IPC、会话刷新和 Hooks 事件轮询。
- `core/services/app-state.service.ts`：将统一 Agent 事件归并到终端状态。
- `dialogs/session-center-dialog.ts`：历史会话搜索、过滤和恢复入口。
- `dialogs/claude-launch-dialog.ts`：新会话名称、模型和 MCP 选择。
- `dialogs/agent-settings-dialog.ts`：诊断、模型/API 和 MCP Profile 管理。
- `inspector/inspector-panel.ts`：展示真实 Claude 状态和最近事件。

## 会话索引

`ClaudeCodeAdapter` 递归读取 Claude 配置目录中的 `projects/**/*.jsonl`，
从容解析工作目录、分支、模型、标题和消息数量。未知字段和无法解析的单行
会被忽略，扫描过程不写入、重命名或删除 Claude 原始文件。

AgentDock 将解析结果 Upsert 到 `agent_sessions`。收藏、别名等扩展数据应
继续存放在 AgentDock 数据库中，不能回写 Claude JSONL。

## 启动与恢复

Windows 检测优先级为：

1. `AGENTDOCK_CLAUDE_PATH`
2. PATH 中的 `claude.exe`
3. PATH 中的 `claude.cmd`
4. npm 和本地二进制常见目录

PowerShell 启动命令使用完整可执行路径。新会话使用 `--name`，历史会话
使用 `--resume <native-session-id>`。模型使用 `--model`，MCP 使用
AgentDock 运行时生成的 `--mcp-config`。

应用重启时只恢复终端配置，不自动重放已退出进程或历史命令。用户需要从
会话中心显式恢复 Claude 会话。

## Hooks 状态链路

AgentDock 为每个 Claude 终端生成隔离的 `--settings` 文件，注册
SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、
PermissionRequest、Notification、Stop 和 SessionEnd 等事件。

Claude 调用 `agentdock.exe hook-event` 后，事件追加到应用数据目录的
JSONL spool。Desktop Core 增量读取 spool，以 `event_key` 去重写入
`agent_events`，再映射为统一终端状态。

## 安全边界

- API Key 使用 `keyring` 写入 Windows Credential Manager。
- SQLite 仅保存 `credential_target`，不保存密钥明文。
- 前端只能读取 `hasCredential`，不能读取已保存密钥。
- 密钥只在 Desktop Core 内解析并注入目标 PTY 环境。
- Workspace 快照、Hook payload 和日志不得包含密钥。
- MCP JSON 在保存前必须通过 JSON 对象校验。

## 数据迁移

`0002_agent_sessions.sql` 新增：

- `agent_sessions`
- `model_profiles`
- `mcp_profiles`
- `agent_events`

迁移使用幂等建表语句，V0.1 Workspace 数据保持兼容。
