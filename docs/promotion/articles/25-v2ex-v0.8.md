# V2EX：分享创造短帖（V0.8.1）

## 标题

[分享创造] Termexo V0.8：在手机浏览器里操作桌面上正在跑的那批终端

## 节点

`分享创造`

## 正文

我是 Termexo 的维护者。这是个 MIT 开源、Windows 上的本地多 Agent 工作台（Claude Code / Codex / OpenCode），刚发了 V0.8.1，主线是远程访问。

边界先说：**仅 Windows**；远程访问面向家庭局域网或 VPN 这类可信网络，自签名证书会让浏览器提示不安全，每台设备要手动确认一次；访问令牌等同于这台电脑上 Termexo 的完整控制权。远程端不能改远程访问设置本身，也不能触发 npm 自更新或原生文件读写，白名单是唯一的授权边界。

打开开关后，手机、平板或另一台电脑用浏览器进来，读写的是桌面上正在运行的同一批 PTY，不是只读镜像，也不另开会话。Agent 卡在等授权的时候，人不在电脑前也能点掉。

手机上拖拽终端会合成滚轮事件交给 xterm 分发，全屏 TUI 也能滚。另外一个 PTY 只有一个尺寸，归正在操作的那一端——手机上开着的时候，桌面端的列数会跟着变，这点得先知道。

Git 视图也改成跟随当前终端，以该终端启动时的 HEAD 为基线，看这次会话动了哪些文件和 Diff。
