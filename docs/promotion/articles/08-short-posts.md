# 社交平台短文案

## GitHub / 开发者群 / 朋友圈

我把 Windows 上同时管理 Claude Code 和 Codex 的工作流做成了一个 MIT 开源项目：Termexo。

它能把多个真实 PTY 终端排成工作台，识别等待输入/授权/完成状态，恢复原生会话，并管理 DeepSeek、MiniMax、GLM、Kimi 等模型 Profile。V0.4.4 又补齐了 Codex 第三方模型 metadata、事务化切换和供应商余量面板。

一条命令体验：`npx termexo@latest`

GitHub：https://github.com/gemron/Termexo

欢迎真实反馈、Issue 和 PR；确实有帮助的话，也欢迎 Star。
