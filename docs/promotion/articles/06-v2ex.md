# V2EX：分享创造短帖

## 标题

[分享创造] Termexo：把 Claude Code、Codex 和多模型供应商收进一个 Windows 工作台

## 节点

`分享创造`

## 正文

最近把自己一直在用的多 Agent 工作台 Termexo 整理到 V0.4.4 了，MIT 开源。

它主要解决我同时开多个 Claude Code / Codex 时的几个痛点：

- 多个真实 PTY 终端排成网格，Workspace 记住目录和布局；
- 识别运行、思考、等待输入、等待授权、完成和失败；
- 只读发现原生会话，用 `claude --resume` / `codex resume` 接着工作；
- 管理多账号与模型 Profile，支持 DeepSeek、MiniMax、GLM、Kimi 等兼容 Endpoint；
- 模型切换失败会恢复原会话和配置；
- 供应商余额、本地 Token 和 Plan 估算会区分数据来源；
- API Key 存在 Windows Credential Manager，不需要 Termexo 账号或云服务。

![Termexo 工作台](../assets/termexo-workbench.png)

Windows 10/11 x64 可以直接跑：

```powershell
npx termexo@latest
```

GitHub：https://github.com/gemron/Termexo
