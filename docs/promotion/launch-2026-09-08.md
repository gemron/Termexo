## 本版统一事实与披露

- 应用级单次输出订阅，按终端 ID 分发；输出处理在 Angular 变更检测之外注册，界面状态按帧合并。
- 重连历史回放只重画终端，不重复交给任务看板、交接包和启动检测读取器分析。
- 草稿内存维护，空闲批量保存，关闭或进入后台立即保存；尺寸认领改由焦点/点击触发，减少逐键存储和布局操作。
- Claude Code 1M 上下文模型标识配置；Claude/Codex 推理强度分别校验；单终端启动可覆盖 Profile。
- 1M 上下文和推理档位依赖 CLI、模型、账号及供应商支持，不承诺配置入口能扩大模型能力。
- 空工作空间直接提供 Claude Code、Codex CLI、OpenCode、Shell 入口。
- MIT 开源 Windows 工作台；Agent CLI 与模型服务仍需独立配置。文稿披露 AI 整理，不编造性能倍数或独立测试结果。

## 待发中文长稿（思否/公众号备用）

标题：Termexo V0.8.2：改善多终端输入响应，新增上下文与推理强度配置

Termexo V0.8.2 已于 2026 年 9 月 8 日发布。Termexo 是 MIT 开源的 Windows 多 Agent 工作台，统一管理 Claude Code、Codex CLI、OpenCode 和真实终端。本次更新主要改善持续输出时的输入响应与启动恢复，并补充模型配置选项。

### 减少多终端输出对输入的干扰

此前每个终端分别订阅同一输出事件流，再在回调中按终端 ID 过滤。终端越多，同一份输出触发的重复回调、反序列化和 Angular 变更检测就越多。V0.8.2 改为应用级单次订阅，按终端 ID 分发，在变更检测之外处理输出，并按帧合并界面刷新，减少 Agent 快速输出时与键盘输入争用主线程的工作。

### 恢复历史只负责重画终端

重连回放的历史输出此前会再次进入任务看板、交接包和启动检测读取器，拖慢恢复，也可能重复统计。现在历史回放只用于恢复终端画面，不再重复分析已经处理过的内容。

### 简化每次按键的处理

草稿改为在内存中维护、空闲时批量写入应急存储，窗口关闭或进入后台时立即保存。终端尺寸认领由焦点和点击触发，减少逐键执行的存储操作、脱敏处理和同步布局测量。

### 模型 Profile 新增上下文与推理选项

Claude Code 可配置 1M 上下文模型标识；Claude 与 Codex 可分别设置推理强度，避免把两种 CLI 不同的档位混用。启动对话框支持仅为当前终端临时覆盖，默认跟随模型配置。

1M 上下文和各推理档位的实际可用性取决于所用 CLI、模型、账号与供应商支持；Termexo 提供配置入口，不扩展模型自身能力。

### 空工作空间可直接启动 Agent

空工作空间现在直接提供 Claude Code、Codex CLI、OpenCode 和 Shell 入口，与标签栏使用同一份列表。

### 下载与升级

Windows 用户可下载 V0.8.2 安装包，或运行 `npx termexo@latest`。使用 Agent 仍需配置对应 CLI 和模型服务。
