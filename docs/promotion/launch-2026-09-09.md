## 统一文案

Termexo v0.8.3 已发布，推荐正在使用旧版的朋友更新，尤其是经常同时运行多个 Agent、遇到输入卡顿或启动变慢的用户。

Termexo 是 MIT 开源的 Windows 多 Agent 工作台，统一管理 Claude Code、Codex CLI、OpenCode 和真实终端。本次更新重点改善输入响应、Git 状态刷新与任务执行体验。

### 打字更跟手

后台 Git 查询和事件同步此前会与按键写入排在同一条 IPC 线程上。v0.8.3 将这些后台命令移到线程池，减少按键等待。官方发布记录中的实测按键延迟 p99 从 514 毫秒降到 19 毫秒；这是发布方测量结果，不代表所有设备和负载下都能达到相同数值。

### Git 状态按需刷新

仓库状态改为监听文件变化，有改动时再读取，并保留 60 秒兜底检查。一次查询所需的 Git 进程由 5–8 个减少到 1 个，减少后台重复工作。

### 减少历史事件积累，改善启动读取

事件只保留界面需要的字段，读取位置跨重启保存，已读完的缓存会被截断，并在启动时清理超过 30 天的事件。官方记录中，启动时的事件读取从一秒多缩短到几毫秒。这个数字指事件读取环节，并非整个应用的启动时间。

### 任务可以中途调整

运行中的任务可追加补充指令，通过同一个 Agent 会话继续处理；也可以中止任务并保留终端与会话，后续继续执行或放回待办。

### Agent 状态更清楚

顶部概览集中展示当前 Agent、余量、代码变更、分支与运行数量。下方详情改为可折叠区块，并记住展开状态。

### 下载与更新

推荐升级至 v0.8.3，体验更流畅的多 Agent 工作过程。

首次升级启动时需要完整处理一次旧事件缓存，可能仍会慢一次，之后按增量读取。
