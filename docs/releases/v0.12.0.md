## What's new

- **Linux desktop and npm support.** Linux x64 now joins Windows and both macOS architectures in the same release. Install the Debian package or launch the complete cached application with `npx termexo@0.12.0`. Linux packages preserve the application resources and include native desktop, PTY and npm installation checks. Thanks to [wuyh410](https://github.com/wuyh410) for [#45](https://github.com/gemron/Termexo/pull/45).
- **Built-in One Ring workflows.** Launch and review agent workflows from the workbench, with bundled MCP resources, native worker routing and improved Codex hook identity and Windows path handling. Includes the One Ring integration from [#41](https://github.com/gemron/Termexo/pull/41).
- **More useful saved actions.** Search and organize common commands, choose a working directory and set per-command environment variables. AI-discovered actions include directory and environment settings for review, editing and reuse.
- **Separate remote viewing and control.** Share an independent read-only link while retaining the control connection. Viewer permissions are checked by the backend.
- **Clearer account authorization.** Login terminals show the selected account, authorization steps and persistent verification feedback. Invalid or expired codes produce a retry path; an unanswered code submission shows a timeout after 30 seconds. A fresh attempt replaces only that account's login terminal, and existing credentials alone cannot count as a successful new login.
- **Mobile terminal input and rendering.** Touch clients use an independent message field while the terminal's hidden native input is disabled. Failed sends retain drafts, and output batching and atomic history replay reduce unnecessary redraws.
- **Better content previews and labels.** Improved file and website navigation, Markdown rendering, preview controls, German toolbar labels and quota labels. Developer instructions now explain staging One Ring resources before running Cargo on a fresh checkout.
- **Dependency updates.** Includes the Angular and Rust dependency updates from [#43](https://github.com/gemron/Termexo/pull/43).

## 本次更新

- **Linux 桌面与 npm 分发。** Linux x64 与 Windows、两种 macOS 架构统一发布，提供 Debian 安装包及保留完整应用资源的压缩包，可通过 `npx termexo@0.12.0` 启动。发布流程包含原生桌面、终端和 npm 安装检查。感谢 [wuyh410](https://github.com/wuyh410) 在 [#45](https://github.com/gemron/Termexo/pull/45) 中提供支持。
- **内置 One Ring 工作流。** 在工作台启动和审核 Agent 工作流，内置 MCP 资源，完善原生 worker 路由、Codex hook 身份和 Windows 路径处理，包含 [#41](https://github.com/gemron/Termexo/pull/41) 的集成。
- **常用操作更完整。** 支持搜索和整理命令，为每条命令设置工作目录与环境变量；AI 识别结果也会携带目录和环境设置，确认前可查看和编辑。
- **远程只读与控制连接并存。** 提供独立只读链接，保留可控制连接，后端校验只读访问权限。
- **多账号授权流程更清楚。** 显示当前账号、授权步骤和持续的验证状态；错误或过期授权码有失败反馈，发送后 30 秒没有结果会显示等待超时提示。可重新获取授权链接，只替换对应账号的登录终端；旧凭据不会直接被判为本次登录成功。
- **手机输入与终端重绘优化。** 触屏客户端使用独立输入栏，禁用终端内部隐藏输入框，处理输出追焦问题；发送失败保留草稿，合并输出和完整历史重放减少重复重绘。
- **预览与文字优化。** 改善文件和网页导航、Markdown 渲染、预览操作、德语工具栏和额度标签；开发说明补充首次直接运行 Cargo 前准备 One Ring 资源的步骤。
- **依赖更新。** 包含 [#43](https://github.com/gemron/Termexo/pull/43) 的 Angular 与 Rust 依赖更新。

## Install / 安装

- Windows x64: choose the EXE or MSI. / 选择 EXE 或 MSI 安装包。
- macOS: choose the DMG for Apple Silicon (`aarch64`) or Intel (`x64`). / 按芯片选择 DMG。
- Linux x64: install the `.deb`, or use the application `.tar.gz` or npm. GTK 3, WebKitGTK 4.1 and Secret Service are required; see the [Linux guide](https://github.com/gemron/Termexo/blob/v0.12.0/docs/linux.md). / 可安装 `.deb` 或使用完整应用压缩包、npm；系统依赖见 Linux 说明。
- npm: `npx termexo@0.12.0` or `npm install --global termexo@0.12.0`.
- Restart Termexo and Agent terminals after updating. / 更新后重启 Termexo，并重新打开 Agent 终端。

Windows packages remain unsigned; macOS uses ad-hoc signing without Apple notarization. The mobile input and account authorization changes have automated coverage; physical Android Chrome/Edge and real OAuth account flows still require device verification.

Windows 安装包仍未正式签名，macOS 采用 ad-hoc 签名、尚未公证。手机输入与账号授权改动已覆盖自动化测试，安卓 Chrome/Edge 真机和真实 OAuth 授权流程仍需实际复测。
