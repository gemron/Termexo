# Termexo v0.13.0

- 模型设置和启动选项更集中。可从终端标题栏切换 Claude Code 或 Codex 会话的模型。
- 标签栏更紧凑。通过「新建」打开常用操作、任务、Git 和会话中心，从「⋯」菜单访问应用设置和远程工具。
- 终端标题栏提供两个布局操作。「最大化终端」隐藏工作区、工作状态和标签栏。「占满布局」保留工作台栏位。点击标题栏按钮或按 Shift+Esc 可恢复。
- 可保存远程主机、检查连接状态，并在独立窗口打开主机。Git 差异导航、终端中的常用操作和 Antigravity 余量显示也有改进。

- Simplified model settings and launch options. Change the Claude Code or Codex session's model from its terminal header.
- A compact tab bar. Use **New** to open saved actions, tasks, Git and session history, and find application settings and remote tools under **⋯**.
- Two terminal layout controls. **Maximize terminal** hides the workspace sidebar, Work status and tabs. **Fill terminal layout** expands the pane while keeping the surrounding workbench accessible. Use the title-bar button or **Shift+Esc** to restore.
- Save remote hosts, check their connection status and open each in its own window. This release also improves Git diff navigation, terminal controls for saved actions and Antigravity quota reporting.

Install with `npx termexo@0.13.0`, or choose a Windows, macOS or Linux package below.

Windows packages are unsigned unless built with SignPath. macOS packages use ad-hoc signing and are not notarized.
