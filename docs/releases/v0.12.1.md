# Termexo v0.12.1

移除内置 One Ring 功能及其运行时，减小桌面安装包与 npm 包体积。

- 移除 One Ring 面板、工作流编排、内部 Worker 通道和启动参数注入。
- Windows、macOS、Linux 和 npm 分发均不再打包其 Node.js、引擎及插件资源。
- 旧工作流终端重新打开时使用普通 Agent 启动流程，保留原有工作流数据。
- npm 启动器支持 Node.js 18.18 及以上版本；开发者直接运行 Cargo 无需准备工作流资源。
- 保留 Linux、公开 MCP、远程只读、命令目录与环境变量、多账号和手机终端输入等功能。

Remove the built-in One Ring panel, engine, internal Worker bridge and bundled Node.js runtime from all distributions. Previously managed workflow terminals reopen as ordinary agent sessions; saved workflow data remains available on disk. The npm launcher supports Node.js 18.18 or later. Linux support, public MCP tools, read-only remote access, command environments, account flows and mobile terminal improvements remain available.

Install with `npx termexo@0.12.1`, or download the package for your platform below.

Windows packages are unsigned; macOS packages use ad-hoc signing and are not notarized.
