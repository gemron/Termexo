# Termexo v0.17.2

- **远程网页终端刷新更稳定。** 清屏指令先到时，终端会短暂保留原画面，等新内容到达后一起刷新，减少输出过程中闪出黑屏的情况。
- **通过 MCP 创建或更新任务时可选择账号和工具。** 可以给单个任务指定 Agent 账号及要加载的 MCP 工具配置。MCP 服务也可按需开启局域网访问，连接仍需令牌。
- **OpenCode 更可靠地收到任务指令。** 如果启动后输入框仍然是空的，Termexo 会再尝试发送一次，减少首条指令丢失的情况。
- **官网新增 Termexo Fleet 预览。** 可以在官网和项目首页查看预览截图。

在下方下载对应系统的安装包，或运行 `npx termexo@0.17.2`。

## English

- **Smoother terminal updates in the remote browser.** When an erase command arrives ahead of its replacement content, the terminal briefly keeps the previous screen visible and applies the update together.
- **Choose accounts and tools per task through MCP.** When creating or updating a task through MCP, you can select the agent account and which MCP profiles to load. LAN access to the MCP server is opt-in and still requires a token.
- **More reliable OpenCode task prompts.** Termexo retries the first prompt once if OpenCode still shows an empty composer after startup.
- **Termexo Fleet preview on the website.** The website and project README now include preview screenshots.
