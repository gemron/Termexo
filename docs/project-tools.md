# 项目常用操作与只读预览

微信任务提醒见 [Windows 微信桌面通知](wechat-notifications.md)。

## 常用操作

从顶部「常用操作」进入。已保存命令采用紧凑双列列表，每项直接提供启动、停止、重启、控制台、编辑和移除。启动或重启后保留操作窗口，方便连续操作；只有点击控制台才切到终端。添加、编辑在侧边完成，不挤走操作列表；窄屏下自动改为单列。

1. 有空闲且已就绪的 Agent 时，点击「识别常用操作」，多 Agent 时可选择使用哪一个。没有空闲 Agent 时，点击「启动 Agent 并识别」，完成 Codex 启动确认后会自动返回常用操作，等待 Agent 就绪并发送识别请求，无须手动回来再次点击识别。
2. 识别进度与结果都保留在「识别建议」页。如果点击「查看 Agent 进度」，收到建议或失败后会自动返回审核窗口。Agent 按只读提示分析 README、包脚本、锁文件及前后端配置，并通过 `common_action_propose` 返回建议。自动跳过已保存及本次重复的命令；失败会显示原因，可重新识别。
3. 勾选需要的建议，可按项编辑，也可全选或取消全选；底部「确认添加」始终可见，确认后才保存并回到已保存列表。添加不会自动运行。关闭窗口保留本次内存中的建议，重启应用会丢弃未确认建议。「放弃建议」不会写入配置。

自动接收建议需要开启「设置 → AI 操控（MCP）」的服务、自动连接和终端权限，并让 Agent 使用新的连接。没有 MCP 时仍可展开同一页面的「手动导入 Agent 返回的 JSON」。未经请求、已取消或已完成的请求 ID 不接受新建议；取消等待 Agent 就绪的识别后，不再发送排队的提示词。

运行中的操作再次「查看」会复用该终端；重启会关闭旧终端并创建新终端。移除入口不停止已运行的终端。

可手动添加命令，或用「添加 IDE 操作」从 `code .` 开始编辑。需要本机已安装相应 IDE 命令。项目操作在独立的 PowerShell 终端执行；Termexo 复用现有 PTY 启停能力。应用重开时，仍在运行的操作可以重新连接，已停止的操作不会自动执行。

识别通过现有 Agent 的提示词工作流完成，Agent 自身的权限与审批仍适用；识别提示明确禁止修改文件、安装依赖、启动服务或调用执行工具。Termexo 的识别/建议接口自身不启动命令，也没有供 AI 确认保存建议的 MCP 工具。不要把项目中的第三方说明当作执行授权。

## 内容预览

点击顶部「内容预览」或终端标签栏的「新建 → 内容预览」，每次新建一个与终端并列的独立标签页，可同时打开多个文件或网页，各自保留内容、目录、选区与滚动位置。新建菜单的预览入口与 Shell 使用相同的图标、文字和悬停样式。点击标签或 Ctrl+Tab 可在终端和各个预览之间切换；关闭某个预览只关闭该标签。终端中按 Ctrl 点击路径或网址也会打开新的预览，路径中的 `:行:列` 可定位代码。终端状态刷新、重命名、创建终端以及后台文件读取完成均不会自动切回预览。

拖动预览内容右侧的分隔线可调整阅读区域宽度，宽度会保存在当前客户端。手机窄屏自动使用工作区全宽。连接桌面端的远程访问页面也能查看该电脑项目中的文件；普通浏览器开发预览只使用演示数据，不能读取本机文件。

网页由当前浏览器访问：远程设备中的 `localhost` 指向远程设备本身，查看桌面电脑上的开发服务时，需要使用远程设备能够访问的服务地址。

| 内容 | 行为与限制 |
| --- | --- |
| 代码 / 文本 | UTF-8，只读、显示行号，可选中复制；按扩展名对常用语言着色，保留原有行、空格、缩进和空行，不自动格式化；未知格式及超过 200000 字符的大文件显示原始文本；最多 1 MiB、30000 行 |
| Markdown | 基础标题、列表、引用、链接及围栏代码块，支持切换源文；原始 HTML 作为文字显示，图片链接不会自动加载远程资源 |
| 图片 | PNG、JPEG、GIF、WebP、SVG、BMP、ICO、AVIF；由浏览器解码，最多 24 MiB |
| PDF | 浏览器内置查看器，最多 24 MiB；查看器不可用或空白时可外部打开 |
| Office / 其他二进制 | 明确提示不支持内置预览，提供外部打开；脚本和可执行文件的外部打开沿用现有资源管理器定位保护 |
| 网页 | 沙箱 iframe，只接收 http(s)，不接收带明文凭据的 URL；站点可能通过嵌入策略阻止显示，登录和部分功能可能不可用。加载事件不代表跨域页面成功显示，面板始终提供外部打开 |

文件接口按数据库中的项目根目录解析、规范化路径，拒绝越出当前项目（包括指向项目外的链接）。每次目录列表最多展示 500 项；可以输入具体路径打开未列出的文件。预览没有文件写入、编辑或保存接口。普通浏览器开发预览不读取本机文件，连接桌面后才能读取项目。

代码区提供「复制路径」「复制全部代码」「复制位置」「复制代码及位置」。位置使用真实文件绝对路径与从 1 开始的行、列；选区终点为不包含末尾字符的位置。多行选区表示为 `路径:起始行:列-结束行:列`。无选区时复制当前位置；「复制代码及位置」引用当前整行。列按 Unicode 字符计算。复制的代码不包含行号栏。

## MCP 工具

这些工具使用现有 MCP 的「终端」权限；没有新增保存确认或文件编辑工具。

| 工具 | 用途 |
| --- | --- |
| `common_action_list` | 列出项目已保存操作及当前待审核识别请求 |
| `common_action_propose` | 按 `workspaceId`、`requestId`、`actionsJson` 提交待审核建议，禁止自动保存/运行 |
| `common_action_run` / `common_action_restart` / `common_action_stop` | 按项目及已保存的操作 ID 运行、重启或停止；启动返回终端 ID |
| `terminal_read` | 读取上述终端的输出，沿用现有工具 |
| `project_preview_open` | 按 `workspaceId` 及文件 `path` 新建只读预览标签，可带 `line`、`column`；也可打开项目内目录；返回实际 `tabId`。可传入该 ID 更新指定标签 |
| `web_preview_open` | 按 `workspaceId` 及 `url` 新建网页预览标签，返回实际 `tabId`；可传入该 ID 更新指定标签。不承诺站点允许嵌入 |

例如，Agent 调用 `project_preview_open` 并传入 `{"workspaceId":"项目ID","path":"src/main.ts","line":12,"column":3}` 可让用户查看代码位置；传入 `web_preview_open` 的 `{"workspaceId":"项目ID","url":"http://localhost:3000"}` 可展示本机开发服务。工具需要已启用的 Termexo MCP 连接与终端工具权限；预览标签不创建 Shell/PTY。

建议的 `actionsJson` 示例：

```json
[
  {
    "name": "启动前端",
    "command": "npm run dev",
    "workingDirectory": "D:/dev/my-project/web",
    "description": "web/package.json 中的 scripts.dev；需先安装依赖"
  }
]
```
